# Дизайн-ревью WebApp (этап 2, 2 октября 2026)

> Архив от 02.10.2026. Статусы и решения здесь могли устареть; актуальное — в `CLAUDE.md` и `PLAN.md`.

Стенд: WebApp на тестовой базе + заглушка Telegram в Chromium, экран iPhone
430×932 (и 375×667), тёмная и светлая тема, СДО — на правдоподобных
тестовых баллах. Скрины с пометками отправлены владельцу в чат (1–20).
Ничего не меняется без «ок» владельца по номеру. Статус — в PLAN.md.

1. **Чат открывается на старых сообщениях.** С историей вкладка открывается
   сверху, последний ответ — ниже экрана. → При открытии и после ответа —
   прокрутка к последнему сообщению.
2. **«Безопасность» устарела.** Написано «только кто, что открыл и когда», а
   с v5.1.0 староста в /stats видит имена и ники. → Дописать честно.
3. **Светлая тема: бледные надписи** — сроки «завтра/через 3 дн./8.10»,
   ЗАЧ/ЭКЗ, «идёт сейчас», проценты. → Тёмные оттенки тех же цветов только
   для светлой темы.
4. **Легенда баллов неполная**: в полоске 5 цветов, в легенде 3. → Легенда
   из цветов, которые реально есть.
5. **Фильтры поиска в две строки** на iPhone. → Одна строка с прокруткой.
6. **МИРЭА лежит — расписание группы/препода**: строка «Не загрузилось» и
   пустота. → Капибара + «Повторить»; своя группа — из сохранённой копии.

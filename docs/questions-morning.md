## Этап 1 (а) — группы, тариф, лимиты ИИ

**Решения:**
- Все, кто был в боте до обновления, записаны в УИБО-03-24 автоматически —
  ничего не спрашиваем. Новые после `/start` пишут название группы (вопрос —
  в том же приветствии, одним сообщением), в приложении — лист «Из какой ты
  группы?», без группы не закрывается. Сменить — `/group` или «Ещё → Группа».
- Тарифы: своя группа и старосты — ИИ как раньше; другие группы — проба 3
  вопроса в день и не больше 1500 на всех за день (потолок ~5 тыс. ₽ в месяц
  на дешёвой модели), новые конспекты — 3 в неделю (готовые — без лимита);
  подписка — до 100 вопросов в день. Все числа — переменные Railway
  (`AI_TRIAL_DAILY`, `AI_TRIAL_DAY_TOTAL`, `SUMMARY_WEEKLY`, `AI_SUB_DAILY`).
- Подписку пока можно выдать только вручную: `/sub <id> <дней>` у старосты
  (оплаты нет — по плану «сначала люди, потом деньги»).

**Вопросы:**
1. Группу сейчас может выбрать любой — проверки, что человек правда из неё,
   нет. Для расписания это неважно, а для общих дедлайнов и файлов группы
   (этап 1 (б)) — важно: чужой может записаться в УИБО-03-24. Предлагаю так:
   видеть данные группы может любой выбравший её, а **менять общие данные**
   (дедлайны, ДЗ, файлы) — только старосты группы и те, кого они добавили.
   Ок?

## Этап 1 (б) — данные по группам

**Решения:**
- У человека из другой группы — расписание его группы (бот, приложение,
  календарь-подписка), свои общие дедлайны, ДЗ, заметки и файлы; данные
  УИБО-03-24 ему не видны, и наоборот.
- Кто ещё не выбрал группу (только пришёл — его тут же спрашивают), видит
  данные УИБО-03-24, как раньше.
- Старосты групп: человек жмёт «Я староста этой группы» (лист группы) или
  `/iamstarosta`, тебе приходит запрос с кнопками «Одобрить/Отклонить».
  Одобренный добавляет общие дедлайны, ДЗ и заметки своей группы. Это ответ
  на вопрос выше по умолчанию: видеть может любой выбравший группу, менять —
  только одобренные тобой.

**Не сделано (позже):** лента «Подслушано» и голосования — пока только для
УИБО-03-24 (inline-режим уже по группе — этап 1 (д)).

## Этап 1 (в) — СДО других групп

**Решения:**
- Задания СДО другой группы появляются, когда кто-то из неё подключил СДО и
  включил «Делиться заданиями с группой» (лист СДО). Бот берёт из его СДО
  только список заданий и сроки; баллы и работы никто не видит. Без
  согласия — не берём.
- Одинаковая лекция у разных групп (тот же текст) — конспект делается один
  раз и сразу виден у всех; ИИ второй раз не зовётся.

**Не сделано (позже):**
- Файлы курсов для других групп автоматически (как `/sdofiles` у тебя) —
  пока их могут загрузить сами люди группы, файл попадает в их группу.
  Следующий шаг — `/sdofiles` для старост групп со своим входом, с
  повторным использованием уже выгруженных файлов общих курсов потока.
- Векторы поиска по смыслу своей моделью на сервере: смена модели —
  переиндексация всех лекций, лучше делать одним заходом, когда другие
  группы реально придут. Пока поиск по смыслу у них — по словам и на тех же
  векторах Gemini (бесплатный лимит).

## Этап 2 (а) — вход без Telegram

**Решения:**
- Вход в приложение вне Telegram — только через бота: «Войти через Telegram»
  → бот спрашивает «Войти на Chrome · Android?» → «Да, это я». Пароли и
  коды из SMS не нужны, учётка та же. Почту и VK ID не делал — для почты
  нужен сервис отправки писем (это твой выбор и ключ в Railway), спрошу,
  когда приложение будет готово к людям без Telegram.
- Сессия устройства живёт 90 дней и продлевается при заходах; в листе
  «Безопасность» — список устройств, «Выйти» и «Выйти везде».

## Этап 2 (б–д) — PWA, API, пуши, токены

**Решения:**
- PWA: `/app` ставится на экран «Домой» (Android — кнопкой браузера, iPhone —
  подсказка «Поделиться → На экран „Домой“»), без сети показывает последнее
  загруженное. Внутри Telegram ничего не меняется.
- API для своего приложения — `/api/v1/…` (старые пути работают как раньше).
  Убрать путь из API без отметки в снимке теперь нельзя — CI покраснеет.
- Пуши в PWA — своей реализацией (без сторонних сервисов и ключей: ключ
  выводится из токена бота). Все рассылки идут и в Telegram, и пушем на
  устройства, где человек их включил («Уведомления на этом устройстве»).
  В Telegram сообщения приходят как раньше — пуш не заменяет, а дополняет.
- Дизайн-токены — один файл `design/tokens.json` для сайта и приложения.

## Этап 3 (б–ж) — приложение дальше

**Решения:**
- «Помощник» и «Файлы» — входы на вкладке «Учёба» (вкладок по-прежнему
  пять, как в концепте). Сдать файлом — с горящего срока, из «Сдать» и из

- Ответы ИИ и конспекты приходят разметкой Telegram — в приложении её
  разбираю сам (без веб-вставок). Правило «JSON без HTML» для новых API
  остаётся; старые переделывать блоками — когда приложение пойдёт к людям.
- Картинка капибары — белый силуэт: на светлой теме рисую её цветом текста.
  Описания кадров и иконки для ChatGPT — `docs/app/capy-prompts.md`.

# Каналы в Telegram и посты

У проекта два канала: открытый канал новостей для пользователей
([@kapibara_mirea](https://t.me/kapibara_mirea), `LOGIN_CHANNEL`) и канал о
разработке ([@uiboshki_dev](https://t.me/uiboshki_dev), `CHANNEL_ID`). Бот —
админ обоих и публикует посты сам.

## Где лежат посты

- Один пост — одна папка `channel/posts/NN-имя/`: `post.html` в разметке
  Telegram (HTML-подмножество) и картинки.
- Слово `news` в имени папки (`25-news-hello-pinned`) — пост для открытого
  канала, остальные — в канал разработки (`channel_posts.target`).
- Слово `pinned` в имени папки — бот закрепит пост сам.

## Как пост попадает в канал

1. Пост добавляется в PR вместе с выпуском, о котором он рассказывает.
2. После мержа бот присылает старосте превью с кнопкой «В канал».
   Публикация — только по кнопке.
3. Пост всегда одно сообщение: картинки собираются в одну обложку
   (`cover_jpeg`), длинный текст идёт с обложкой сверху как превью ссылки
   `/chimg/<пост>.jpg` (`webapp/routes/channel.py`, нужен `WEBAPP_URL`).

Команды бота (`handlers/channel.py`, `channel_posts.py`):

| Команда | Что делает |
|---|---|
| `/channel` | список постов и что уже вышло |
| `/channel edit 1 4 6` | поправить вышедшие посты текстом из репозитория (обложка и комментарии остаются) |
| `/channel redo` | убрать вышедшее и выпустить заново |

Посты с обложкой нельзя править из приложения Telegram: снимается превью.
Если пост всё же поправили в Telegram, его текст сначала переносится в
`post.html`, и только потом — `/channel edit` или `redo`.

## Как писать

- Голос автора, от первого лица единственного числа («я хотел», «я думал»).
- По-человечески: что сделано и зачем, с настоящим кодом и пояснениями.
- Разметка — только бесплатная: цитаты, раскрывающиеся цитаты, спойлеры,
  блоки кода.
- Исторические посты выходят в день публикации, даты событий пишутся в
  тексте. Скриншоты в них — из своего времени: приложение тех дней
  снимается со стенда из старого коммита (`git worktree` + подменённая дата
  сервера и браузера), в посте строка «восстановлено из кода тех дней».
- Про VPN — словом «КВН», без слов об обходе блокировок. Про параллельных
  ИИ-агентов не писать. Однокурсников по именам не называть без их согласия.
- Без мата. Оформление — по [брендбуку](brandbook.md).
- Строка «📣 Новости Капибары — @канал» есть в `/start`, `/help`, `/app` и
  описании бота (`login_channel.news_line`).

# Архитектурные решения (ADR)

Короткие записки на один экран: что решили, почему и что отвергли. Нужны,
чтобы через полгода не переигрывать решение заново и не гадать, «почему так».

Новое решение — новый файл `NNNN-коротко.md` по образцу ниже. Старое не
переписываем: если передумали, пишем новое со ссылкой «заменяет NNNN», а у
старого меняем статус.

| № | Решение | Статус |
| --- | --- | --- |
| [0001](0001-package-layout.md) | Код сервера — пакет `kapibara/`, папки по темам | принято |
| [0002](0002-layers.md) | Слои и направление импортов | принято |
| [0003](0003-safe-moves.md) | Перенос модулей через переадресацию `sys.modules` | принято |
| [0004](0004-errors.md) | Обработка ошибок: границы, узкие типы, без молчания | принято |
| [0005](0005-safe-deploy.md) | Выкладка: только зелёный CI, `/ready`, автооткат | принято |
| [0006](0006-ratchet.md) | Храповик вместо «починить всё разом» | принято |
| [0007](0007-no-import-cycles.md) | Без кругов импортов, и внутри слоя тоже | принято |

Образец:

    # NNNN. Заголовок

    Статус: принято (дата) | заменено NNNN
    ## Контекст — что за проблема, цифры
    ## Решение — что делаем
    ## Почему не иначе — какие варианты отвергли
    ## Последствия — что меняется, чем платим

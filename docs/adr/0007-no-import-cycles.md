# 0007. Без кругов импортов, и внутри слоя тоже

Статус: принято (03.11.2026)

## Контекст
Слои ([0002](0002-layers.md)) запрещают импорт снизу вверх, но внутри одного
слоя модули брали друг у друга по кругу: 59 модулей в клубках, самые большие —
весь `database/` (14) и `features/` (30). Пример круга: синк СДО → понятные
названия → курсы → синк. Круг держался только на импортах внутри функций.

## Решение
Кругов нет совсем: храповик считает `cycle_modules` (с импортами внутри
функций), потолок — 0, новый круг сразу красит CI. Как разрывать:

- **Общее — вниз.** Мелочь, которую берут двое, уходит в маленький модуль без
  сети и базы: `sdo/courses`, `sdo/pages`, `schedule/hidden`,
  `lectures/extract`, `core/crypto`, `database/settings`.
- **«После X сделать Y» — вверх.** Оркестрация живёт слоем выше обоих:
  `pulse/service` (вошёл в Пульс → подтянуть посещения).
- **Кэш в памяти не тянут к себе — он записывается сам** (`core/forget`):
  privacy не импортирует каждый модуль с данными человека.
- На старом месте остаётся тот же объект (`from новый import имя`), тест —
  `tests/test_moved_modules.py`.

## Почему не иначе
Слить модули из круга в один — получится файл на тысячу строк. Оставить круг
на импортах внутри функций — зависимость видна только в проде, когда правка
одного модуля роняет другой через цепочку.

## Последствия
Перед новым импортом стоит спросить, кто кого знает. Если CI покраснел от
круга, нужно вынести общее вниз, а не прятать импорт в функцию: функцию
храповик тоже видит.

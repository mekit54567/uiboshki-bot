## Принятые решения

- **Пульс МИРЭА.** Кука Пульса с сервера не принимается (401). Защиту
  **не обходим**; путь — официальный доступ, Никита пишет разработчикам
  RTU-TC (t.me/rtu_tc). Пульс — по желанию, поверх СДО, только свои данные
  каждого, в Пульс ничего не пишем. Нужный метод известен:
  `LessonService/GetAvailableLessonsOfVisitingLogs(date)` (посещения по датам).
  Пока доступа нет — посещения по баллам СДО (`attendance.py`).
- **Правила БРС** (сверено с Никитой): итог = семестр + экзамен, пороги
  40/60/80. Автоматом можно 3 или 4 (4 — от 60), 5 автоматом не ставят.
  Максимум за экзамен = «Семестровый контроль» (40). 75 % зачтённых работ
  нужно и для автомата, и для допуска к экзамену; экзамен сдан, когда
  «Семестровый контроль» > 0.
- **Донат и роадмап** (Никита 18.10): роадмап видят все, кто задонатил любую
  сумму (от 50 ₽), — как спасибо, не как покупка. Роадмапа в коде ещё нет:
  сделать после отправки в App Store (на iPhone доната нет). Тогда заменить в
  `/donate` фразу «ничего не открывает» и спросить кассы (ЮKassa, Robokassa),
  можно ли самозанятому так принимать добровольные платежи. Открытый вопрос:
  что поправить в экране `/donate` в боте — Никита отметил «доработка» без
  текста, спросить.
- **iPhone-сборка**: без «Капибары+», цен, оплаты и доната (правило App Store
  3.1.1). Об оплате — только вне приложения (бот, сайт, канал).
- **Подписка**: цена первых 149 ₽ навсегда для оплативших по ней; полная —
  `/plus stage full` только по слову Никиты; рассылка `/plusnews` — только по

- **Ачивки**: 25 штук, ранги «Рассвет · Полдень · Сумерки · Полночь». За

## iPhone и Android

- iPhone: IPA собирает GitHub Actions (задача `app-build`, ios). Никита ставит
  через AltServer на Windows и AltStore, бесплатный Apple ID — приложение
  живёт 7 дней, обновлять в AltStore в той же Wi-Fi. Имя для Apple
  латиницей «Kapibara» (кириллица в `CFBundleDisplayName` ломает AltServer),
  на экране «Капибара» из `InfoPlist.strings`.
- Право Sign in with Apple в подпись не добавлено: AltStore такую сборку не
  ставит. Добавить вместе с подписью для App Store, когда будет аккаунт.
- 120 Гц в Safari и PWA: Настройки → Safari → Дополнения → «Переключатели
  функциональности» → выключить «Prefer Page Rendering Updates near 60fps».
- Android и RuStore: подписанной сборки пока нет; аккаунт разработчика
  RuStore — за Никитой.

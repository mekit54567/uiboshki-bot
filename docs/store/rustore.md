# RuStore — что вставить в консоль

По порядку:

1. Ключ подписи и подписанный APK — [android-key.md](android-key.md) (один раз).
2. Аккаунт разработчика: https://console.rustore.ru → войти через VK ID →
   «Владелец». Аккаунт создаётся как **физлицо** — для бесплатного приложения
   хватает (самозанятость и ИНН — только для продаж через RuStore, раздел
   «Монетизация»). Так сделано 21.10.2026.
3. **Добавить приложение** → «Универсальное», «Бесплатное» (навсегда), название в
   консоли `Капибара` → **Загрузить → Версия** (не «Предзаказ») → APK →
   шаги ниже → **Отправить на модерацию**.

Шаги загрузки версии (консоль на 21.10.2026):

- **Файлы**: APK + комментарий модератору — **не больше 180 знаков**:
  `Вход: «Вход по коду доступа» внизу экрана входа, код <REVIEW_CODE> — демо-аккаунт с примером данных. Расписание есть и без входа. Покупок внутри нет.`
  Нужна переменная `REVIEW_CODE` на сервере (`kap env`, от 12 знаков) — без
  неё кнопки входа по коду нет.
- **Технические сведения**: типы данных — ID устройства или другие
  идентификаторы; Файлы и документы; Имя; ID пользователей; Другие данные;
  Взаимодействие с приложением; Другой пользовательский контент; Другие
  сообщения в приложениях; Фотографии. Значок «не нашли в манифесте» —
  нормально (фото и файлы — через системное окно, без разрешения).
  Обоснование `POST_NOTIFICATIONS`: `Уведомления по выбору пользователя:
  расписание на день, напоминание перед парой, новые задания и баллы из СДО.
  Включаются и выключаются в настройках приложения.` Интеграции — пусто.
- **Информация**: карточка ниже. Теги — только из списка консоли: Календарь,
  Личные помощники, Блокноты, Самосовершенствование, Часы, будильник и таймер.
- **Медиафайлы**: иконка и скриншоты (раздел ниже).

Пакет (`ru.uiboshki.app`) и подпись RuStore возьмёт из APK. Номер сборки растёт
сам; для новой версии — снова Run workflow с версией больше прошлой
(`1.0.1`…) → **Загрузить версию** → APK → «Что нового».

Ограничения консоли (длина текстов, размеры картинок) могут меняться — если
консоль ругается, она пишет, что именно не так; тексты ниже с запасом.

Капибара — неофициальное приложение студентов РТУ МИРЭА для учёбы: расписание, сроки сдачи, баллы и лекции в одном месте. Его делает студент для своей группы и всех, кому пригодится. Приложение не связано с администрацией университета.

Сегодня
• Какая пара идёт, сколько до конца, в каком кабинете и корпусе следующая.
• Подсказка, если следующая пара в другом корпусе.

Неделя
• Расписание твоей группы по неделям — списком или по дням.

Сдать

Учёба

Ещё

Вход — через Telegram, VK ID или Яндекс ID. Подключение СДО — по желанию, своим входом; данные СДО видишь только ты.

Всё основное — бесплатно. Для тех, кто хочет больше вопросов помощнику и поддержать проект, есть «Капибара+» — оформляется на сайте uiboshki.ru.

## Возраст — почему 16+

В приложении есть то, что пишут люди (заметки, ДЗ группы, «Обсуждение группы» под
парой), и ответы ИИ — заранее их не проверишь. Жалобы и «скрыть автора» есть, но
16+ честнее и студентам не мешает. Если в анкете RuStore спрашивают по пунктам —
насилия, мата, рекламы, азартных игр, покупок внутри приложения **нет**;
пользовательский контент и общение — **есть**.

## Данные пользователей (если RuStore спросит)

То же, что в политике (`legal_texts.py`): имя и id из Telegram/VK/Яндекса, группа и
настройки, что и когда открывал (без содержимого), личные сроки и заметки, вопросы и
фото к помощнику, по желанию — вход в СДО (кука хранится зашифрованной) и баллы.
Рекламы и сторонних счётчиков нет, данные не продаём. Сервер и база — в России.

## Оплата

«Капибару+» в RuStore упоминать можно: оплата идёт на сайте (ЮKassa), внутри
приложения покупок нет. Если модерация попросит платёжку RuStore — ответить, что в
приложении ничего не продаётся, а подписка оформляется на сайте.

## Разрешения в APK

Сборка показывает список в Summary запуска. Сейчас (1.0.0): `INTERNET`,
`ACCESS_NETWORK_STATE`, `WAKE_LOCK`, `POST_NOTIFICATIONS` и приём пушей
(`c2dm.permission.RECEIVE`) — от уведомлений; из них RuStore считает
чувствительным только `POST_NOTIFICATIONS` (обоснование — выше).
Фото и файлы выбираются системным окном, без доступа ко всей галерее.

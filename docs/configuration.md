# Настройка (переменные окружения)

Все параметры сервера задаются переменными окружения (читаются в `config.py` и профильных модулях); значения секретов хранятся только в окружении сервера и не попадают ни в репозиторий, ни в чат.

Переменные меняются на сервере командой `kap env`, после чего нужен `kap restart`; какие из них сейчас работают, показывает `kap check` (`tools/env_check.py`). Устройство подсистем описано в [architecture.md](architecture.md).

## Основное

| Переменная | Зачем | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен бота; из него же выводятся ключи, которые не заданы отдельно | обязательна |
| `BOT_USERNAME` | Имя бота | `uiboshkibot` |
| `GROUP_NAME` | Название своей группы | `УИБО-03-24` |
| `GROUP_PROGRAM` | Направление группы | «Бизнес-информатика» |
| `STAROSTA_ID` | Telegram id старосты; можно несколько через запятую (второй аккаунт), первый основной (`is_starosta()`) | пусто |
| `GROUP_CHAT_ID` | Чат группы: по нему определяются участники своей группы; пока не задан, лента «Подслушано» выключена, чат запоминается, когда староста добавляет бота | не задан |
| `ICAL_URL` | Календарь своей группы (определяет `config.HOME_GROUP_ID`) | группа УИБО-03-24 на зеркале расписания |
| `DATABASE_PATH` | Путь к базе SQLite | задаётся запуском |
| `WEBAPP_URL` | Публичный адрес WebApp; без него inline-карточки идут текстом, не работают превью постов `/chimg/…` и ссылки оплаты | пусто |
| `PORT` | Порт веб-сервера | `8080` |
| `HOSTING` | Ключ хостинга для текста политики (`privacy.HOSTS`) | задаётся при развёртывании |
| `AMVERA` | Флаг прежней платформы: при `1` база всегда лежит на `/data` (`docker/start.sh`) | не задан |
| `OPTIONAL_SUBJECTS` | Предметы по выбору: пары скрыты, пока человек не ответит «хожу» (`optional_subjects.py`, `/optional`) | «Военная кафедра» |

## ИИ

| Переменная | Зачем | По умолчанию |
|---|---|---|
| `GEMINI_API_KEY` | Ключ Gemini, основного провайдера | пусто |
| `GEMINI_MODEL` | Основная модель Gemini | задаётся в `config.py` |
| `GEMINI_FALLBACK_MODELS` | Запасные модели через запятую на случай 429; пропавшая у Google (404) пропускается, основная после 429 идёт после запасных | `gemini-flash-latest,gemini-2.5-flash` |
| `DEEPSEEK_API_KEY` | Ключ DeepSeek, опциональный провайдер | пусто |
| `OPENROUTER_API_KEY` | Ключ OpenRouter: `/aitest`, запасная модель, «Подумать ещё» | пусто |

| `AI_SPARE_MODEL` | Модель OpenRouter на случай, когда у всех Gemini лимит 429; классификатор и `/aitest` её не зовут; пусто — без запасной | `inclusionai/ling-3.0-flash-vl` |
| `AI_MAIN` | Кому запасная модель основная, а Gemini запасная: `all` — всем, `plus` — старосте и подписчикам «Капибары+», `me` — только старостам, `gemini` — никому. Переключается без деплоя командой `/aimain` (settings `ai_main`) | `all` |
| `AI_TRIAL_DAILY` | Проба ИИ для тарифа `base` (другие группы), вопросов в день на человека | задаётся в `plans.py`/`ai_quota.py` |
| `AI_TRIAL_DAY_TOTAL` | Общий дневной предел пробы для тарифа `base` | то же |
| `SUMMARY_WEEKLY` | Конспектов лекций в неделю для тарифа `base` | то же |
| `AI_SUB_DAILY` | Вопросов в день для тарифа `sub` (подписка) | то же |
| `AI_THINK_MODEL` | Модель «Подумать ещё» (платная через OpenRouter, `data_collection: deny`, не `:free`) | DeepSeek V4.1 Flash |
| `AI_THINK_DAILY` | Лимит «Подумать ещё» на человека в день | `10` |
| `AI_THINK_DAY_USD` | Дневной лимит трат на «Подумать ещё» на всех, в долларах | задаётся в `think.py` |
| `AITEST_BUDGET_USD` | Бюджет одного прогона `/aitest` | задаётся в `ai_bench.py` |
| `AITEST_JUDGE` | Модель-судья в `/aitest` | задаётся в `ai_bench.py` |
| `AITEST_SKIP_VENDORS` | Вендоры, которых OpenRouter закрыл для аккаунта (OpenAI, Anthropic, Google); Gemini проверяется своим ключом (`gemini-direct`) | OpenAI, Anthropic, Google |

Тарифы определяет `plans.py`: `own` — своя группа и старосты, `sub` — подписка, `base` — остальные.

## СДО

| Переменная | Зачем | По умолчанию |
|---|---|---|
| `SDO_SESSION_COOKIE` | Общая кука `MoodleSession` старосты; используется, когда у старосты нет своего входа | пусто |
| `SDO_SYNC_INTERVAL_HOURS` | Период синка дедлайнов, часов (то же для заданий других групп, `group_sync.py`) | `6` |
| `SDO_CRYPT_KEY` | Ключ шифрования входов студентов в СДО (Fernet); отдельный секрет. При смене все входы перешифровываются (`sdo_accounts.rotate_all`), старые ключи остаются запасными | не задан |
| `SDO_CRYPT_PASSPHRASE` | То же в виде парольной фразы | не задана |
| `SDO_KEEP_COURSES` | Курсы, которые не отсекаются как «не этого семестра» (`KEEP_COURSES`) | «Учебный отдел» |
| `PULSE_COOKIE` | Вход старосты в Пульс МИРЭА для разведки схем `/pulseprobe` (только чтение своих данных) | не задана |

Без `SDO_CRYPT_KEY` и `SDO_CRYPT_PASSPHRASE` ключ выводится из `BOT_TOKEN`; `/status` об этом предупреждает.

## Сеть

Без этих переменных все запросы идут напрямую. Через прокси ходят только хосты из `PROXY_HOSTS`; расписание МИРЭА, СДО, VK и Яндекс идут напрямую.

| Переменная | Зачем | По умолчанию |
|---|---|---|
| `OUT_PROXY` | Прокси для запросов за границу (http или socks5) | пусто (на сервере его ставит `docker/start.sh` из `XRAY_CONFIG`) |
| `PROXY_HOSTS` | Хосты, которые идут через `OUT_PROXY` | Gemini и OpenRouter |
| `TG_PROXY` | Прокси для Telegram | значение `OUT_PROXY` |
| `TELEGRAM_API_BASE` | Свой адрес Bot API | официальный |
| `XRAY_CONFIG` | Секрет: ссылка `vless://` или JSON приложения прокси; `docker/start.sh` поднимает по нему Xray и ставит `OUT_PROXY` | пусто |
| `PROXY_COUNTRY` | Страна выхода прокси; попадает в текст политики о передаче запросов за границу (`privacy.backup_texts`) | не задана |

Проверка с сервера — команда `/netcheck`. Новые исходящие запросы за границу идут через `net.client()`, бот создаётся с `session=net.tg_session()`.

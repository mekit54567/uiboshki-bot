- Пульс МИРЭА · эксперимент: в приложении у старосты — «Ещё → Пульс · эксперимент». Вход в Пульс окном (пароль видит только сайт МИРЭА), кнопка «Собрать» сама обходит разделы Пульса и записывает, что сайт запрашивает и получает (только чтение). Токены и куки — только формой: длина и срок жизни. Журнал → сервер (`/api/pulse/lab`, `pulse_lab.py` раскладывает gRPC-Web по полям) → архив старосте в бота. Вход живёт только на телефоне.
- Пульс · эксперимент: обход больше не уходит в ЛКС по ссылке «на главную» (жмёт только ссылки внутри Пульса, а ушёл — возвращается), ищет разделы в коде сайта, находит круглую кнопку QR, запросы не теряются при перезагрузке страницы. Скрипты обхода сервер может подменить (`pulse_lab_kit.json`, `/api/pulse/lab/kit`) — правки разведки без новой сборки.
